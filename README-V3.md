# NGOVIO V3

Landing V3 orientada a conversión.

## Qué cambia

- Hero con propuesta de valor más clara.
- Productos agrupados por objetivo: Crear, Lanzar, Vender, IA, Construir, Organizar y Bundle.
- Eliminadas métricas y testimonios ficticios.
- Pricing simplificado y sin "valor individual" inventado.
- FAQ centrada en objeciones de compra.
- CTA final y sticky CTA.
- Responsive mobile.
- SEO básico y Open Graph.
- Gumroad centralizado en `src/gumroad.js`.

## Antes de publicar

1. Sustituye las 17 URLs placeholder de `src/gumroad.js`.
2. Confirma que el producto 17 realmente incluye los 17 productos y que €199 es el precio real.
3. Ajusta las condiciones de licencia al texto legal real.
4. Añade términos, privacidad y política de reembolso reales.
5. Ejecuta:

```bash
npm install
npm run build
npm run preview
```

## Importante

No se han inventado métricas, testimonios, descuentos ni URLs de compra.
